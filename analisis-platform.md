## Analisis Platform Pemrograman (Web, Desktop, Mobile)

Di bawah ini adalah tabel analisis mengenai perbandingan platform pengembangan perangkat lunak antara Web, Desktop, dan Mobile.

| Aspek               | Web                                                                                                                | Desktop                                                                                                                 | Mobile                                                                                                                                       |
| :------------------ | :----------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| **Bahasa utama**    | HTML, CSS, JavaScript (TypeScript)                                                                                 | C++, C#, Java, Swift, Python, Rust                                                                                      | Kotlin (Android), Swift (iOS), Dart (Flutter), JavaScript (React Native)                                                                     |
| **Arsitektur**      | Client-Server, Multi-tier, SPA (Single Page Application), Microservices                                            | Monolithic, Client-Server, MVC, MVVM                                                                                    | Client-Server, MVVM, Clean Architecture, MVC                                                                                                 |
| **Cara distribusi** | Melalui Web Browser (URL), PWA via App Store                                                                       | Installer (exe, dmg, deb, msi), Package Manager (pacman, apt, winget, brew), App Store (Microsoft Store, Mac App Store) | App Store (Google Play Store, Apple App Store), File APK (Android)                                                                           |
| **Keunggulan**      | Akses universal lintas perangkat, pembaruan instan (tanpa intervensi user), tidak memakan banyak penyimpanan lokal | Performa tinggi, akses langsung ke hardware/sistem, dapat berjalan offline, kontrol penuh atas resource sistem          | Portabilitas tinggi (dibawa ke mana-mana), akses fitur hardware spesifik (GPS, kamera, sensor), UX dioptimalkan untuk layar sentuh           |
| **Keterbatasan**    | Akses hardware terbatas, performa bergantung pada browser & kecepatan internet, keamanan lebih rentan              | Memerlukan proses instalasi, pembaruan manual oleh user, terikat pada sistem operasi tertentu, ukuran file besar        | Sumber daya terbatas (baterai, RAM), ukuran layar kecil, distribusi melalui app store yang ketat (review), fragmentasi OS (terutama Android) |
| **Contoh aplikasi** | Google Docs, Facebook Web, Shopee Web, YouTube, Figma Web                                                          | Microsoft Word, Adobe Photoshop, Visual Studio Code, Spotify Desktop, Zoom                                              | WhatsApp, Instagram, Gojek, Mobile Legends, TikTok, Google Maps                                                                              |
